L0 Absent     : !existsSync(CLAUDE.md) && !existsSync(AGENTS.md)
L1 Basic      : file exists (resolver+existsSync) AND git ls-files --error-unmatch <file> exits 0
L2 Scoped     : /\bMUST\b|\bMUST NOT\b|\bNEVER\b/.test(content)

                  proxy1: statSync(claudeMd).mtimeMs within 90 days

Rung labels (exact): Basic, Scoped, Structured, Abstracted, Maintained, Adaptive
